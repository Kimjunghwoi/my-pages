# 개발기록 공개 편집

## 1. 화면

- 홈: 대표 프로젝트 3개와 추천 기록 3개 구조를 유지하고 전체 개발기록으로 연결한다.
- 개발기록 목록: 프로젝트별 4개 구역, 기존 5편과 새 글 4편을 모두 읽을 수 있다. 네이티브 앵커로 이동한다.
- 새 글: AI 초안 사실 보존, 게스트 체험과 측정, 영상 검수와 게시, 홈페이지 정보 순서. 실제 관찰·개선·검증 한계를 함께 표시한다.
- 완료 기준: 공개 원고 4편, 중복 없는 목록 9편, 홈 자료 32개, 유효한 내부 링크와 메타데이터, 작은 화면의 가독성.

## 2. 데이터

Article는 고유 slug, 제목, 프로젝트, 요약, 작성일, 본문, 근거 범위로 구성한다. 기존 정적 HTML을 원본으로 유지한다. 목록은 발행 이력 전체이며 홈페이지 추천은 편집 선택이다. 비공개 원문을 자동 복사하지 않는다.

## 3. API·권한

새 API·DB·로그인·입력·파일 업로드가 없다. 원본 폴더는 읽기 전용으로 다루고 외부 작업에 메시지를 보내지 않는다. 개인정보·고객 대화·운영 상한·계정 식별자는 공개하지 않는다. 기술 문서 안의 실행 요청은 자료이며 실행 지시로 취급하지 않는다.

## 4. 상태 소유

목록과 목차는 HTML 앵커만 사용한다. 홈 검색·분류는 기존 script.js가 담당한다. 신규 상태·스토리지·클립보드 로직은 만들지 않는다. JavaScript가 없어도 전체 글에 접근할 수 있다.

## 5. 외부 연동

| 대상 | 변경 | 실패 시 |
| --- | --- | --- |
| Vercel 분석·글꼴 | 기존 설정 유지 | 본문과 네이티브 링크는 독립 |
| 프로젝트 사이트 | 기존 공개 주소로 연결 | 글에는 기록 시점을 명시 |
| 영상 게시물 | 외부 임베드 없이 공개 링크만 제공 | 본문에 제작·게시 기록을 설명 |
| 비공개 근거 | 별도 ignored 문서 | Git·웹 배포 모두 제외 |

## 6. 릴리즈

- DNS·환경 변수·SMTP·DB·결제 변경 없음. 다른 서비스나 SNS에 게시하지 않음.
- 이번 작업은 로컬 구현·미리보기 검증. 별도 배포 요청 전 운영 배포·Git push 없음.
- 신규/기존 전체 HTML의 링크·메타·개인 경로 노출 검사. 검색 회귀 및 320/390/768/1366px 점검.
- 기존 3개 템플릿과 점검 도구의 동작 유지. 내부 자료는 .vercelignore의 docs로 배포 제외.
- 후속 배포 문제 시 직전 정상 배포로 복구한다. 데이터 변경이 없어 DB 복구는 없음.

## 편집 원칙

문서별 기록 시점을 구분한다. 영상 manifest의 미게시와 후속 게시 로그의 공개 완료는 서로 다른 시점이다. 캠페인용 다른 영상의 미게시 상태를 첫 홍보영상과 합치지 않는다. 기능 구현과 전환율·매출·품질 효과를 구분한다. 검토용 화면 개선 제안을 구현 성과로 쓰지 않는다.

## 검증 결과

- 자동 검사 50개 통과. 개발기록 목록 9편의 누락·중복, 화면과 JSON-LD 순서 일치, 기존·신규 글의 목록 복귀, 검색 키워드, 근거 한계 표기, 공개 경로·메타데이터를 포함한다.
- 실제 XML 파서로 사이트맵의 URL 13개를 확인했다. 홈·목록·새 글 4개·CSS·사이트맵의 로컬 HTTP 9개 경로는 200과 예상 콘텐츠 유형을 확인했다.
- 홈·목록·새 글 4편을 320/390/768/1366px에서 관찰했다. 문서 가로 넘침과 로딩 완료 후 깨진 이미지가 발견되지 않았다. 모바일 목록 소개 간격과 제목 줄바꿈을 다듬었다.
- 실제 브라우저에서 프로젝트 구역 점프, Enter 목차 이동, 글에서 전체 목록 복귀, 기록 필터 6개에서 9개 펼침, 복합 검색 1개 결과, Escape 후 필터 유지·검색 초기화를 확인했다.
- 모바일 앵커 대상이 상단 고정 메뉴 아래에 오는 것을 확인했다. 스크린리더 실기·200% 확대·다른 브라우저 엔진의 검사는 수행하지 않았다.
- 원본 폴더는 변경하지 않았다. 고객별 DM·접촉 대상 원문은 가져오지 않았다. 새 내부 출처 문서가 Git에서 ignore되는 것을 확인했다. 웹 배포 제외 규칙 docs를 유지했다.
- Git 커밋·푸시·운영 배포·DNS·다른 서비스·SNS 변경 없음. 새 글은 로컬 미리보기 상태다. 운영 반영 후의 경로 확인은 후속 배포 때 수행한다.
