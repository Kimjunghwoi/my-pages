# 벤치마크 후속 구현 범위

## 화면과 성공 기준

- 홈: 프로젝트 이름과 용도를 그림보다 먼저 파악하고, CSV 예시를 비교하거나 목적별 입문 경로를 선택한다. 기존 세 서비스로 가는 CTA를 유지한다.
- `stories/column-harbor.html`: 원본 보존, 로컬 처리, 위험 점검과 자동 수정의 차이를 설명하는 제작 기록. 실제 점검기로 연결한다.
- 390x844 / 1366x768에서 첫 프로젝트 이름 노출, 의미 있는 작은 글씨 개선, 320px에서도 가로 넘침 없음이 목표다.

## 데이터 모델

- Project: 기존 세 서비스. 정적 HTML이 원본이며 개수와 외부 목적지를 유지한다.
- Resource: 기존 19개와 내부 제작기 1개. 제작기는 `data`로 분류하고 `project` 필터는 세 실제 서비스만 보여준다.
- Starter path: 면접 / AI 부업 / 데이터 실무의 고정된 추천 링크 순서. 실제 노션·서비스 URL만 사용한다.
- Demo: 합성 상품 코드 `00123`. `number` / `text` 두 상태. 업로드·자유 입력·저장 없음.
- Story: 실제 확인 날짜, 제작자, 설명, 한계, 공개 참고 링크. 방문·매출 수치나 미공개 원고·소스는 공개하지 않는다.

## API와 인증

신규 서버 API, 로그인, 결제, DB, 쿠키, 환경 변수는 없다. 기존 외부 서비스는 일반 링크로만 연결한다. 데모에는 네트워크 요청이 없으므로 API 오류 계약도 없다.

## 상태 소유

- 기존 `script.js`: 자료 검색·필터·URL 상태와 더 보기. 내부 제작기도 일반 자료와 동일하게 검색한다.
- 신규 `experiences.js`: DOM별 데모의 선택 상태. 상태 결과는 `textContent` 및 `hidden`, `aria-pressed`로 반영한다. 다른 기능과 독립 실행한다.
- 입문 경로: 네이티브 `details/summary`. JavaScript가 없어도 이용할 수 있다.
- 제작기: 정적 HTML, 상태 없음. 홈페이지 필터 스크립트를 로딩하지 않는다.
- 데모 스크립트 실패/비활성: 숫자로 해석한 예시와 텍스트로 유지한 예시를 모두 읽을 수 있다. 작동하지 않는 버튼은 숨긴다.

## 제작기 근거

Column Harbor 공개 버전의 소스 커밋 `d0c14461a0222b5d6b74df5c708be5b1a3d7c6e8`과 현재 로컬 `lib/csv.ts`, `components/csv-checker.tsx`의 차이가 없음을 확인했다. 파일 선택은 `arrayBuffer()`와 UTF-8 디코딩, 점검은 `analyzeCsv()`로 처리한다. 원본 문자열을 유지하고 정규식 등 규칙으로 위험 신호를 만든다. 로컬 다른 변경 파일과 운영·성과 기록은 이번 작업에서 수정하거나 공개하지 않는다.

## 검증 기록

- `node --check script.js`, `node --check experiences.js`, `node --test tests/*.test.mjs`: 26개 통과.
- 정적 계약 검사와 실제 스크립트에 대한 DOM 어댑터 기반 동작 검사를 구분해 구성했다. 어댑터 검사는 실제 브라우저 렌더링이나 보조기기 검증을 대체하지 않는다.
- 브라우저에서 직접 확인: CSV 숫자/텍스트 비교와 상태 알림, Enter 키, 입문 경로 열기·닫기, 복합 검색, 분류 URL, 앞/뒤 이동, 빈 결과, 제작기 목차와 본문. 검색창에 별도 입력이 섞여 후반 검색 회귀 검사는 브라우저 포커스를 사용하지 않는 자동 검사로 분리했다.
- 외부 분석 서비스의 새 요금제나 사용자 정의 이벤트는 도입하지 않았다. `ads.txt`와 기존 Vercel 스크립트도 유지했다.
