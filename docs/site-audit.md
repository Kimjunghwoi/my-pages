확인일: 2026-09-13. 사용자가 연 Porkbun DNS 목록에서 공개 웹 서비스 세 개를 확인했고, 사용자가 이 세 개만 반영하도록 확정했습니다. DNS 레코드는 변경하지 않았습니다.

## Interviewer Lens

- https://interview.jhsoftlabs.com/
- 개발자 면접 답변의 약한 지점, 예상 꼬리질문, 개선 초안을 제공하는 AI 진단 프로젝트입니다. 면접 준비 글 모음이나 현직 면접관의 직접 리뷰 서비스로 소개하지 않습니다.
- 첫 진단을 로그인 없이 시작할 수 있습니다. 베타 안내에서 실제 결제 없이 구매 의향을 확인한다고 설명하므로 유료 상품 판매 중이라고 주장하지 않습니다.
- 홈페이지의 진단 그림은 기능 이해를 위한 재구성 예시이며 실제 이용자 결과가 아닙니다.

## Deep Constellation

- https://image.jhsoftlabs.com/
- 현재 주력은 미용실 홍보 콘텐츠 제작입니다. 이미지, 디자인, 게시글을 묶어 첫 홍보물 또는 월간 콘텐츠로 제공합니다. AI 모델과 헤어 룩북은 옵션이며 다른 뷰티 업종은 상담 대상입니다.
- 단순 프로젝트 사례 아카이브라는 기존 설명을 제거했습니다. 자주 변할 수 있는 가격은 홈페이지에 복제하지 않았습니다.
- 홈페이지에 사용한 두 이미지는 이 사이트의 `/assets/campaigns/salon-opening.png`, `/assets/campaigns/salon-season.png`입니다. 가상 매장의 AI 제작 예시이며 실제 고객 실적이나 시술 결과로 표현하지 않습니다.
- 로컬 WebP는 원본 비율을 유지한 경량 버전입니다.

## Column Harbor

- https://csv.jhsoftlabs.com/
- 무료 CSV 점검 도구와 Excel/Google Sheets/CSV 실무 가이드를 제공하는 영문 프로젝트입니다. CSV를 업로드하지 않고 브라우저에서 원본 값을 살펴보며 가져오기 위험을 점검합니다.
- 앞자리 0, 긴 ID, 모호한 날짜, 열 개수 등 위험 신호를 표시합니다. 이미 손실된 값의 복구나 자동 수정을 보장하지 않습니다.
- 자료 분류에 `데이터 실무`를 추가하고, 앞자리 0 보존 / 한 열로 열리는 CSV / 숨은 공백 / CSV→JSON 가이드 네 개를 연결했습니다. 각 가이드는 영문임을 표시했습니다.
