# 기존 글을 실행 가능한 실습으로 보강

## 목적과 범위

AdSense의 상세 거절 원인은 확인되지 않았다. 링크성 판정이나 글 수 부족을 확정하지 않고, 메인 도메인 안에서 읽기·실행·결과 비교를 끝낼 수 있도록 기존 두 글을 개선했다. 승인 보장, 재검토 요청, DNS 변경, 광고 설정 변경은 작업 범위가 아니다.

- Power Query 병합 글: 외부 입력 파일 없이 실행하는 전체 M 쿼리, 세 모드, 중복 키 오류 실험, 실제 Excel 엔진 관측 결과.
- AI 재시도 글: 저장 전 실패·응답 유실·입력 변경·한도 초과를 구분하는 Node.js 학습 모델, 출력 비교, 일부러 회귀를 만드는 세 실험.
- 각 글에 전체 코드 미리보기와 동일 파일 다운로드를 제공한다. 게시일은 유지하고 수정일·사이트맵만 갱신한다.
- 메인과 가이드 목록에서 새 실습 내용을 안내한다. 기존 프로젝트 세 개와 공개 콘텐츠 경로, 사이트맵 20개 URL은 유지한다.

## 검증 결과

`python scripts/verify-merge-lab.py`는 별도 Excel 인스턴스의 임시 통합문서에서 공개 M 파일을 실행한다. Windows Excel과 pywin32가 필요하며, 사용자 문서를 열거나 저장하지 않는다. 원본 쿼리를 읽고 결과를 표준 출력으로 내보낸다.

Excel 16.0 build 5569.0, Microsoft Mashup OLE DB에서 9개 검사가 통과했다. `merge-lab-evidence-2026-10-05.json`의 SHA-256은 공개 M 코드와 연결된다. audit는 4행/42/매치 수 2·2·1·0, expanded는 6행/72, corrected는 4행/42이며 미일치 S4도 보존된다. 조회 키 중복을 넣으면 지정한 오류로 멈춘다. UI 메뉴 클릭, Mac·웹 Excel, 외부 DB 연결이나 query folding은 검증하지 않았다.

초기 검증 하네스의 전역 문자열 치환은 Mode 대입문뿐 아니라 조건식까지 바꿔 expanded가 audit 결과를 반환하게 했다. 치환을 첫 번째 일치로 제한한 후 다시 실행했다. 이는 검증 코드 결함으로, Excel 엔진 결함이나 사용자의 과거 서비스 장애로 기록하지 않는다.

`node stories/retry-lab.mjs`는 게시한 다섯 줄을 출력한다. 학습 모델은 단일 프로세스 동기 메모리 상태이며 실제 AI 호출, DB 트랜잭션, 결제, 다중 서버 동시성을 구현하지 않는다. 세 가지 의도적 회귀도 모두 비정상 종료하는지 테스트했다.

`node scripts/verify-pages.mjs`: 69개 테스트 통과, 공개 파일 50개. 본문 코드/다운로드 일치, Node 실행 결과, 고의 회귀, M 검증 기록의 해시, 링크·앵커·공개 파일 허용 목록을 확인했다. 빌드에는 두 개의 지정된 실습 파일만 추가했으며 docs/scripts/tests는 여전히 제외한다.

브라우저에서 M 코드 펼침, 390px 모바일 목차 이동과 가로 넘침 없음, 재시도 코드의 390px/320px 가로 넘침 없음, 실제 다운로드 버튼 동작을 확인했다. 가로로 긴 코드는 코드 영역 내부에서 스크롤한다.

## 배포와 복구

기존 Cloudflare Pages Git integration으로 main을 배포한다. 환경 변수, DB, DNS 변경은 없다. 공개 페이지의 새 절, 파일 응답과 바이트, 수정일, ads.txt, 정상 404를 확인한다. 문제가 생기면 이 작업 커밋을 revert한 후 같은 경로로 배포한다. 다른 프로젝트나 도메인 연결을 바꿀 필요는 없다.
