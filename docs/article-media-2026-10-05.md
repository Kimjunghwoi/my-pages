# 글의 이해를 돕는 시각 자료

## 반영 범위

- Power Query 병합: S1·S2가 각각 A1·A2에 연결되는 SVG 설명 이미지. 본문 합성 데이터의 4행/42 → 6행/72를 사용한다.
- 앞자리 0: 화면에 같은 00123이 보이더라도 내부 값과 ISTEXT가 다른 비교 이미지. 기존 실제 Excel 검증 관측을 도식화했다.
- AI 재시도: 확정 전 실패와 확정 후 응답 유실을 구분하는 SVG. 공개된 동기 메모리 학습 예제와 일치시키며 운영 DB 검증으로 소개하지 않는다.
- 영상 제작 회고: 9월 13일의 기존 24초 무음 완성본을 직접 재생한다. 새 AI 영상이나 실제 고객·시술 사례로 소개하지 않는다.

SVG 세 장은 편집 가능한 자체 설명 도식이다. 실제 Excel·운영 화면 스크린샷인 것처럼 만들지 않았다. 이미지마다 대체 텍스트, 크기, 캡션, 원본 크게 보기 링크가 있다. 본문과 표를 이미지로 대체하지 않았다.

## 영상 출처와 공개 범위

동일 프로젝트의 first-promo 제작 문서, 장면 타이밍, manifest, 보관 무음본을 확인했다. SHA-256은 `2d7730fa5abdb1855dee1feb8cd96c394a2bf15c2edd035a6308b7134daac97a`이며 원본을 수정하지 않고 복사했다. 크기 6,877,083 bytes, H.264, 1080×1920, 24초, 오디오 스트림 없음. FFprobe로 다시 읽고 FFmpeg 전체 디코딩도 오류 없이 완료했다.

대표 이미지는 이미 공개된 salon-season.webp를 재사용한다. 영상의 첫 프레임이라고 표시하지 않는다. 영상 안의 당시 상담 안내는 현재 활동 상태와 다르므로 활동 중단 전 제작물임을 바로 옆에 명시했다. 기존 활동 중단 회고 링크와 날짜를 유지한다.

제작 문서·게시 계정 정보·원본 폴더 전체는 배포하지 않는다. 공개할 무음 MP4 하나만 빌드 허용 목록에 지정했다. 임의의 다른 MP4는 배포되지 않는 회귀 검사를 추가했다.

## 성능과 접근성

설명 SVG는 외부 이미지·스크립트·폰트 요청을 포함하지 않는다. 본문 이미지에는 lazy/async 로딩과 명시적 크기를 사용한다. 작은 화면에서는 비율을 유지하고 크게 보기 링크로 원본을 확인할 수 있다.

영상은 자동재생·반복 없이 controls/playsinline/preload=none을 사용한다. YouTube iframe 또는 새 추적 스크립트는 없다. 약 6.9MB를 재생 전에 안내하며, 영상 없이 읽을 수 있는 일곱 장면 설명과 MP4 다운로드를 제공한다. 본문에서 보존하는 외부 YouTube 링크는 직접 선택했을 때만 해당 서비스로 이동한다.

## 검증 및 배포

Node 자동 검사 72개 통과. 이미지 값, 대체 텍스트, SVG의 활성 코드 부재, 파일 해시, 영상 초기 설정, 빌드 내 파일 보존 및 비공개 파일 제외를 확인한다. 배포 파일은 총 54개이며 사이트맵 20개 URL과 기존 글의 최초 게시일을 유지한다.

브라우저에서 24초 끝까지 재생되어 ended=true이고 디코딩 오류가 없음을 확인했다. 초기에는 paused=true, readyState=0으로 자동재생하지 않았다. 일곱 장면 설명 펼침, 390px/320px에서 미디어의 문서 가로 넘침 없음도 확인했다. 이미지 지연 로딩 전에 fit-content 부모가 좁아지는 문제를 발견해 부모 너비를 명시적으로 확보했다.

기존 Cloudflare Pages Git 배포를 사용한다. DNS·AdSense 재검토·광고 설정은 변경하지 않는다. 공개 이미지 응답과 비디오 Range 응답을 확인하고, 문제가 있으면 이 변경 커밋을 revert해 같은 경로로 배포한다. 시각 자료 추가가 AdSense 승인을 보장한다는 뜻은 아니다.
