# 메인 화면의 강조와 읽는 순서 개선

## 범위

소유자가 앞서 제안한 메인 화면 개선을 모두 진행하도록 요청했다. 기존 종이색·초록색·회몬 캐릭터와 정적 HTML 구조는 유지하고, 장식보다 대표 콘텐츠와 읽기 경로를 바꾼다. 시작 소스는 `719d467`이며 원격 main과 일치했다.

1. 첫 화면에서 CSV·Excel 문제 해결과 직접 만든 도구라는 용도를 구체적으로 설명하고 가이드/프로젝트 진입을 분리한다.
2. 앞자리 0 보존 글을 대표 가이드로, 나머지 세 증상을 보조 목록으로 배치한다. 표시된 00123과 실제 숫자 123/텍스트 00123의 차이는 기존 합성 자료의 설명이며 새 Excel 실행이나 실제 화면이라고 주장하지 않는다.
3. 프로젝트 DOM 순서를 Column Harbor, Interviewer Lens, 밤팡으로 바꾼다. 중단한 Deep Constellation은 별도 작은 회고 영역에 남긴다. 네 프로젝트의 주소·기존 앵커와 자료 목록 항목은 보존한다. 별도 서비스 소스와 DNS는 수정하지 않는다.
4. 홈 전용 `home.css`에서 설명 글자 크기·명도 대비를 높이고 대표 글, 서비스, 실험 기록의 시각적 리듬을 나눈다. 서브페이지의 본문 스타일이나 게시일을 일괄 바꾸지 않는다.
5. 실험 기록 아래 광고용 HTML template을 **비활성**으로 준비한다. template은 문서에 렌더링되지 않으므로 빈 박스·새 광고 요청·레이아웃 공간이 없다. 실제 광고 코드, 슬롯 ID, 새 추적 스크립트는 추가하지 않는다.

## 보존과 경계

한국어 가이드 4편, 개발기록 10편, 링크 자료 38개와 검색·필터·공유 상태·뒤로가기, 프로젝트의 고정 데이터 데모, 개인정보 안내·AdSense 소유 확인·ads.txt를 유지한다. 신규 글 수나 이용 실적을 만들지 않는다. 루트 sitemap lastmod만 실제 변경일로 맞춘다. 이 디자인 변경이나 광고 자리 준비를 AdSense 승인 조건·효과로 표현하지 않는다.

실제 광고 활성화는 별도 운영 작업이다. 소유자의 명시적 지시와 실제 광고 단위, 개인정보 안내 및 필요한 동의 처리, 광고/콘텐츠 구분, 모바일 레이아웃·미게재 상태 검증 후 진행한다. 비활성 template에 임의 슬롯을 넣거나 URL·검색어로 활성화하지 않는다. 현재 재검토 요청·계정·광고 설정은 변경하지 않는다.

## 검증 계획과 배포

기존 검사 외에 구체적인 진입 문구, 대표 글/보조 글 분리, 프로젝트의 실제 DOM 순서, 비활성 광고 경계와 홈 전용 스타일 적용을 검사한다. Pages 허용 목록에는 `home.css`만 추가하며 문서·테스트·계정 관측은 배포하지 않는다.

데스크톱과 320/390/768/1024px에서 가로 넘침, 실제 글자 크기·프로젝트 그리드, 앵커와 검색·필터·데모를 확인한다. 실제 광고나 광고 수익은 시험하지 않는다. 빌드/공개 HTTP 검사와 실제 브라우저 동작을 구분해 기록한다.

기존 Cloudflare Pages Git 배포를 사용한다. 환경 변수·DB·호스팅·DNS 변경은 없다. 장애 시 이번 변경을 revert해 재배포하거나 직전 성공 Pages 배포로 복구한다. 결과는 검증이 완료된 뒤 아래에 기록한다.

## 로컬 검증 결과

- `node scripts/verify-pages.mjs`: 구문 검사와 테스트 84개 통과. 기존 79개에 메인 강조·프로젝트 순서·광고 비활성 경계 검사 5개를 추가했다. Pages 산출물은 58파일, 7,684,700bytes다.
- 실제 브라우저 viewport를 320/390/768/1024/1280/1440px로 설정해 측정했다. 모두 문서와 카드가 화면 폭 안에 들어온다. 작은 화면의 메뉴 자체는 가로 스크롤을 허용하지만 페이지 전체는 가로로 넘치지 않는다. 첫 설명 글자는 모바일 14px/그 외 15px, 보조 가이드 설명은 14px다.
- 데스크톱 대표 가이드/3열 프로젝트, 태블릿 가로 카드, 모바일 첫 화면/가이드/회고를 직접 확인했다. 홈에서 가이드와 프로젝트로 이동하는 앵커, 중단한 프로젝트 앵커, CSV 숫자/텍스트 비교 버튼이 작동한다.
- 자료 목록은 프로젝트 필터 4개, `밤팡` 검색 1개, 초기화 후 전체 38개/초기 6개 표시를 확인했다. 뒤로가기로 프로젝트 필터와 검색어가 복원된다. 브라우저가 수집한 오류·경고는 없었다.
- 모든 검사 폭에서 렌더링된 광고 영역, 광고 로더, 광고 iframe은 없었다. template 안의 준비된 요소만 존재한다. 실제 광고의 게재·반응형 동작을 검증했다는 의미는 아니다.
- 측정값: `outputs/reviews/homepage-2026-10-20/responsive.json`. 로컬은 `.pages-dist`를 일반 HTTP 서버로 읽었으므로 Pages의 확장자 없는 글 주소 전환은 배포 후 공개 호스트에서 별도 확인한다.

이 검증은 브라우저 모사 viewport와 기능 점검이며 실제 휴대전화, 스크린리더, 검색 색인·사용자 반응·AdSense 승인 결과를 보장하지 않는다.

## 공개 배포 확인

- 앱 커밋 `8cfa07e`를 원격 main으로 push했다. GitHub Site checks와 Cloudflare Pages가 모두 성공했으며 Pages 배포 ID는 `a0801d77-0fa6-4fd6-af7a-323fb773be0e`다. 배포 대상은 기존 `jhsoftlabs` 프로젝트와 `https://jhsoftlabs.com/`이며 계정·환경 변수·DNS 설정을 바꾸지 않았다.
- `node scripts/check-public.mjs`: sitemap 21페이지를 포함한 공개 HTTP 검사 **64건 통과, 실패 0건**. 새 CSS를 포함한 정적 자산이 로컬 산출물과 일치한다. 기존 글 주소 전환·canonical·실제 404·샘플 다운로드 무결성 검사도 포함한다. 기존 검사 도구의 출력 파일을 오늘의 기록 폴더에 복사해 `outputs/reviews/homepage-2026-10-20/public.json`으로 보관했다.
- 공개 브라우저에서 새 메인 문구와 `home.css?v=20261020-editorial`, 네 프로젝트의 실제 DOM 순서, 비활성 광고 상태를 확인했다. 대표 가이드 링크는 확장자 없는 `https://jhsoftlabs.com/data-guides/excel-leading-zeros`로 정상 이동한다.
- 공개 390px 화면에서 문서 폭 375px, 데스크톱 1280px 화면에서 문서 폭 1265px였다. 차이는 세로 스크롤바이며 가로 넘침은 없다. 공개 화면에도 광고 영역이나 로더가 나타나지 않는다.
- 증거: 같은 기록 폴더의 `public-browser.json`, `public-home.png`, `public-mobile.png`. 브라우저 크기 변경은 검사 후 해제했다.

실제 광고 활성화와 AdSense 재검토는 이번 배포에 포함되지 않았다. 검증 결과는 페이지 접근·표시·정적 자산에 관한 결과이며 심사 상태나 승인을 뜻하지 않는다.
