# 밤팡 소개와 가독성 개선

## 공개 화면 확인
- 2026-10-11 https://bogle-chestnut.vercel.app/ 의 공개 v0.10 홈, 장터 지도, 조작 연습을 읽었다.
- 밤팡 장터, 60초 밤판, 간식가게를 별도 모드로 설명한다. 저장 기록은 브라우저 기준이라고 안내한다.
- 기존 브라우저의 별·기록은 사용자 성과 지표로 인용하지 않았다. 기록을 초기화하거나 게임 결과를 새로 저장하지 않았다.
- 기술 스택, 구현 이력, 이용자 수, 수익, 완주 결과는 확인하지 않았으므로 소개에 포함하지 않는다.
- assets/bampang-chestnut.svg는 공개 게임의 inline SVG 밤 캐릭터를 재사용한다. 그림의 path와 색상은 유지하고 장식용 aria-hidden 속성만 제외했다. 소개 그림이며 화면 캡처가 아니다.

## 변경 범위
- /projects/bampang/ 전용 소개, 모드 선택 안내, 플레이 링크, 저장 안내, 목차와 메타데이터.
- 기존 프로젝트 순서를 유지한 4번째 카드와 컬렉션 항목. 전체 38개, 프로젝트 4개. 개발기록 10편은 그대로다.
- 데스크톱 프로젝트 2열, 모바일 1열. 글 본문은 17px, 작은 화면은 16px. 단계별 설명과 주의사항도 16px로 맞춘다.
- 컬렉션 제목과 요약을 16px/14px로 키운다. 디자인 색상과 기존 서비스 경로는 보존한다.
- 신규 페이지는 외부 게임을 자동 실행하거나 분석 스크립트를 추가하지 않는다. 공개 빌드 허용 목록에 소개 HTML/CSS만 포함한다.

## 검증 범위
- `node scripts/verify-pages.mjs`: 75개 테스트 통과, 공개 산출물 57개 / 7,665,966 bytes.
- 1280px에서는 프로젝트 2열, 768/390/320px에서 문서 가로 넘침 없음. 게임 소개의 이미지 로딩, 본문 17px/모바일 16px 확인.
- 게임 소개에서 홈 복귀, 프로젝트 바로가기, `보글보글` 검색으로 단일 결과가 나오는 경로를 브라우저에서 확인했다.
- 기존 앞자리 0 가이드의 모바일 본문·단계별 설명·주의사항 16px와 목차 이동을 확인했다. 스크롤 여백 중복도 줄였다.
- 실제 게임 전체 단계·모든 브라우저의 플레이 검증은 이번 작업 범위가 아니다.

## 배포 경계
- 기존 Cloudflare Pages Git integration을 사용한다. DNS, 환경 변수, DB, 게임 자체 소스는 변경하지 않는다.
- 기존 글의 CSS 쿼리만 갱신한다. 글 작성일과 과거 검증 결과는 수정하지 않는다.
- 배포 전 기준 커밋: `b860cd27fdbc4387b90574133e946f9ba8bfa1cf`. 문제가 생기면 이번 변경 커밋을 revert하여 재배포하거나 기존 Pages 성공 배포로 되돌린다. DNS 롤백은 필요하지 않다.
