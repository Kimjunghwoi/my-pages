# 홈페이지 문장 교정

## 목적과 범위

- 외부 스킬 `epoko77-ai/im-not-ai`의 `humanize-korean`을 검토한 뒤 한국어 문장의 번역투, 추상적인 요약, 불필요한 쉼표를 다듬었다.
- 기준 revision: `b37e0206d31fffd9149bf57168d4d62eb2086bee`, MIT. 검토한 리소스와 스크립트를 작업용 묶음으로 사용했으며 전역 스킬은 설치하지 않았다.
- 홈페이지, 개발기록 목록과 10편, 실무 가이드 목록과 4편, 템플릿 목록, 밤팡 소개의 총 19개 HTML을 교정했다.
- 메인과 글 목록의 요약, 개별 글 도입부를 구체적인 행동과 문제 중심으로 바꿨다. 기술 설명 본문은 필요한 부분만 고쳤다.
- CSS, JavaScript, 서비스 기능, DNS, 호스팅 설정, 광고 설정은 바꾸지 않았다.

## 교정 원칙

- LIGHT 경로로 보수적으로 교정하고 경고가 있는 문서는 원문과 다시 대조한다. 자동 게이트를 사실 확인이나 AI 작성 여부 판정기로 사용하지 않는다.
- 수익을 만들지 못한 기록, 미해결 원인, 합성 예제, 특정 환경에서만 확인한 결과, 전환율을 판단하지 못한 이유를 유지한다.
- 원문에 없는 경험, 고객 반응, 성과 수치나 인과 효과를 추가하지 않는다.
- 제목의 정체성, 작성일과 과거 검증일, 코드와 표, 인용, 링크를 유지한다. 쉼표를 줄인 소제목은 목차에서도 같은 문구를 사용한다.
- 글 수를 늘리거나 인간적인 실수를 의도적으로 삽입하지 않는다. AdSense 승인이나 탐지 회피를 보장하는 작업이 아니다.

## 자동 검증

- 19개 문서의 body 태그와 속성, 코드·표·SVG 블록, 화면에 표시되는 숫자의 다중집합을 원본과 대조했다. 모두 일치했다.
- 스킬 게이트에서 수치 소실과 서법 소실은 없었고 변경률은 30% 경고선 아래였다. 일부 제목의 쉼표 삭제를 제목 소실로 판정하는 경고와 기술 문장의 쉼표 패턴 경고는 별도 검토 대상으로 남겼다.
- 변경률은 추출한 본문의 문자 비교 수치다. HTML 전체나 모든 카드의 span 문구를 포괄하는 수치로 설명하지 않는다.
- `node scripts/verify-pages.mjs`: 최종 수정 후 기존 75개 테스트 모두 통과. 공개 산출물 57개, 7,666,653 bytes.
- 검증을 통과시키려고 테스트 조건이나 기술 예제를 수정하지 않았다.

- 대표 프로젝트 4개, 전체 링크 38개, 개발기록 10편을 유지했다.
- `밤팡` 검색은 1개 결과를 표시하고 검색어를 비우면 38개 중 6개를 보여주는 초기 상태로 돌아왔다.
- 기존 디자인과 본문 글자 크기, 모바일 메뉴를 유지했다.

## 산출물과 공개 경계

- 원본 HTML, 추출 원문, 중간본, 게이트 보고서와 독립 의미 검토는 `_workspace/2026-10-13-001-6910/`에 보관한다.
- Windows용 작업 묶음과 검토 도구는 `outputs/reviews/`에 보관한다. 두 디렉터리는 Git 및 웹 배포 대상이 아니다.
- 공개 빌드는 기존 `.pages-dist` 허용 목록을 사용한다. 원문 스냅샷이나 외부 스킬 소스를 사이트에 게시하지 않는다.
- 독립 검토자는 19개 HTML 전체 문구 변경을 검토했다. 짧아진 요약에서 생략된 구현, 첫 진단 조건, 기술 검사 항목, 검색 상태의 한계를 교체안 10건으로 복원했다. FILTER의 fixture 용어와 새로 삽입된 연결어미 쉼표도 보정했다.
- 홈페이지 회고의 과거 프로젝트 세 개는 최초 작성 커밋 `1cd98bb530e3d1c52c3af362044cc64879c40ad3`(2026-09-13)의 실제 카드 세 개와 같은 날 운영 문서를 대조했다. 현재 네 개라는 사실과 혼동하지 않도록 `이 기록을 작성할 당시`라고 한정했다.
- 최종 추출본문의 변경률은 문서별 0.4~12.1%다. 게이트 8개 OK, 11개 WARN이며 제목 쉼표와 기술 문구 경고를 숨기지 않았다. 스타일 패턴 전멸이나 자동 등급 A를 주장하지 않는다. 자체검증은 5/6, 잔존 S1 0건 항목은 인증하지 않았다.
- 각 실행 폴더에 최종 판정 JSON, 보존한 예비 판정, 요약 주석 하나를 갖춘 final.md를 남겼다.

- 기준 커밋: `a008fd1`. 기존 Cloudflare Pages의 main Git 자동 배포를 사용한다.
