# 영문 가이드 실습 동선 개선

기존 가이드 5편에만 적용한 읽기·실습 경로 개선이다. 새 글, 새 도메인, 광고 단위나 추적 서비스는 추가하지 않았다.

- Power Query 병합: 원본 CSV 두 개 → 병합 절차 → 네 건/합계 42와 확장 여섯 행/반복 합계 72 구분 → 다음 Excel 실습.
- 틀 고정: 기존 B3 경계의 XLSX → 세로/가로 스크롤 검사 → 출력용 머리글과 구분.
- CSV ID 비교: 원본 두 개와 `compare_ids.py` 다운로드 → ID-only 결과 확인 → 선택 필드 변경을 비교하는 브라우저 도구.
- 헤더 승격: 입력/기대 결과와 M 파일 → 실제 `FilePath` 수정 → 헤더 이동·변경의 오류 처리와 다음 스키마 검사.
- 다중 조건 XLOOKUP: 지역별 가격 CSV → 두 조건 수식 → 중복·실제 0·빈 가격 구분 → 단일 키 학습.

글 5편의 상단 제목·여백을 줄이고 실습 파일, 절차, 결과 체크리스트 바로가기를 제공한다. 링크와 다운로드는 네이티브 HTML이며 JavaScript 없이도 접근할 수 있다. 다른 58편의 표시 방식과 기존 서비스·프로필 주소는 유지한다. 원래 게시일과 예제 파일은 보존하고, 실제로 수정한 글의 수정일만 2026-11-18로 기록한다.

## 소스와 산출물

Column Harbor 소스 브랜치 `codex/reader-paths-2026-11-18`, 앱 소스 `789f364a925e4c7ef900fa464314d89e1f0c792f`를 별도 main-origin 작업본에서 검증하고 가져왔다. private 원본 소스·계정 보고서·운영 자료는 공개 산출물에 포함하지 않는다. 빌드된 React HTML/TXT/JS의 사후 치환은 하지 않는다. 스냅샷은 기존과 같은 63가이드·24레슨·10도구이며 메인 사이트맵은 130주소다.

## 검증 범위

- 원본과 파생 소스 각각 125개 테스트, TypeScript 및 정적 빌드/발견 검사 통과. 파생본은 107개 사이트맵 주소와 2,539개 링크를 검사한다.
- 메인 회귀 114개와 로컬 HTTP/자산/비공개 경로 979개 통과.
- 브라우저에서 Python 다운로드 이름과 본문, 체크리스트 앵커·키보드 이동, 글에서 비교 도구로 이동, 실제 비교 결과와 CSV 보고서 다운로드를 확인했다. 동일 합성 입력의 결과는 추가 1·삭제 1·변경 1·미해결 0이다.
- XLSX 다운로드는 기존 검증 파일과 바이트가 일치한다. 이번 작업에서 새 native Excel UI나 M-engine 실행은 하지 않았다.
- 로컬 iframe의 390 CSS px 검사에서 다섯 글의 문서 가로 넘침이 없고, 새 다운로드/빠른 이동 클릭 영역은 최소 44px이다. 실제 모바일 기기·Safari 검증과는 구분한다.
- 새 광고 SDK·GA4·체류시간 이벤트는 없다. 기존 Cloudflare 페이지뷰만 유지하므로 읽기 완료·실제 이용 증가를 이번 변경의 성과로 주장하지 않는다.

## 운영과 복구

소스 변경은 검증 후 별도 작업본 재빌드·가져오기·메인 배포 절차를 따른다. import 날짜는 실행일의 KST 날짜로 기록한다. 공개 검사 보고서는 `node scripts/audit-integrated.mjs https://jhsoftlabs.com outputs/새-릴리즈/public-http.json`처럼 지정해 이전 릴리즈 증빙을 덮어쓰지 않는다.

이번 수정은 기존 통합 이후 주소를 보존하므로 문제가 생기면 직전 통합 Pages 배포로 되돌린다. DNS나 CSV 리디렉션을 바꿀 필요는 없다. 통합 이전 구조까지 되돌리는 별도 작업일 때만 기존 통합 문서의 CSV 우선 복구 순서를 적용한다.

계정 대시보드, 다운로드·화면 증빙, 실제 배포 ID와 공개 응답 결과는 ignored `outputs/reader-paths-2026-11-18/`에 기록한다. AdSense 재신청이나 수집 요청은 이 배포에 포함하지 않는다.
