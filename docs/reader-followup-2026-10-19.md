# 재검토 진행 중 독자 경로 점검

## 현재 관측과 범위

2026-10-19 KST, 소유자가 열어 둔 AdSense 상세 화면에서 `jhsoftlabs.com`은 준비 중이며 요청 시간은 **2026-10-19 09:12**였다. 이는 새 승인이나 새 거절이 아니다. ads.txt는 승인됨으로 표시됐다. 이 작업에서 재검토를 요청하거나 계정·광고·DNS 설정을 바꾸지 않았다.

10월 16일의 [공개 질문](https://support.google.com/adsense/thread/473190174?hl=en)은 10월 19일 조회 시에도 답변이 없었다. 질문에 답글이나 독촉을 추가하지 않았다. 내부 심사 사유나 심사 크롤러가 실제로 본 URL은 여전히 알 수 없다. 아래 수정을 거절 원인 또는 승인 조건으로 설명하지 않는다.

Git 원격을 확인했으며 메인 저장소는 `72dabab`와 같았다. 기존 75개 검사와 Pages 산출물 생성은 통과했다. 한국어 가이드·개발기록에서 사용하는 Microsoft 공식 참고 주소 8개도 HTTP 200과 해당 문서 제목을 반환했다. 근거 없이 링크를 교체하지 않았다. 별도 CSV 저장소는 이전 수정 `24497f4` 이후 원격 변경이 없으며 이번에 수정하지 않는다.

## 고친 독자 경로

1. CSV 한 열 가이드: 미리보기에서 **데이터 변환(Transform Data)**을 눌러 편집기로 넘어가는 단계를 명시했다. 숫자로 추론한 Changed Type을 제거해 원본 00123을 확인한 다음 Text로 지정한다. 이미 손상된 숫자를 Text로 바꾸는 것과 구분한다. 기존 QueryTables 관측을 새 Power Query UI 검증으로 바꾸지 않았다.
2. 앞자리 0 가이드: 이미 제공 중인 CSV→Excel 도구로 합성 예제를 직접 사용하는 경로를 추가했다. 영문 버튼 이름, 3행/2열과 ID 검증, 다운로드 후 확인 수식을 적었다. 모든 셀이 Text이므로 quantity의 숫자 변환은 별도이며 손실된 ID 복구는 불가능하다고 명시한다.
3. 접근성: 390px 공개 화면에서 병합 결과 표는 337px 영역 안에 최대 575px 내용을 가지고 있었으나 영역 이름과 명시적 키보드 진입점이 없었다. 네 가이드의 표와 코드에 이름·포커스 진입점을 정적 HTML로 제공하고 넓은 비교표에는 이동 방법을 적었다. 빠진 본문 건너뛰기 대상과 목차 이름도 맞췄다.
4. 인쇄: 기존 긴 코드/표의 가로 스크롤 규칙은 화면용으로 유지하고 인쇄에서는 내용을 줄바꿈하도록 덮어썼다. 실제 인쇄/PDF 검증과 CSS 정적 검사는 구분한다.

실습 CSV/TSV, M 쿼리, 기존 코드와 표 셀, 최초 게시일과 기존 서비스 주소는 유지한다. 내용이 실질적으로 늘어난 두 글만 수정일·사이트맵 lastmod를 10월 19일로 맞춘다. 포트폴리오 순서·다른 프로젝트·글 수·광고 범위는 바꾸지 않는다. 의존성·서버·입력 수집·추적 코드도 추가하지 않는다.

## 검증과 릴리즈

회귀 검사에는 빠졌던 편집기 단계의 순서, 브라우저 도구의 전체 Text 계약, 정적 키보드 진입점, 날짜 일치와 인쇄 CSS 경계를 추가한다. 코드/표/실습 자산 보존과 실제 브라우저 파일 출력은 별도로 대조한다. 자동 검사 수나 공개 파일 수는 콘텐츠 가치·진짜 독자 반응·AdSense 승인의 증거가 아니다.

검증 후 기존 Cloudflare Pages Git 배포를 사용한다. 환경 변수·DB·호스팅·DNS 변경은 없다. 문제가 생기면 이 변경을 revert해 재배포하거나 직전 성공 Pages 배포로 복구한다. 완료된 검증과 배포 결과는 관측 후 기록한다.

## 배포 전 확인 결과

- `node scripts/verify-pages.mjs`: **79개 검사 통과**, 공개 파일 57개. 기존 75개와 새 회귀 검사 4개다.
- 시작 커밋 `72dabab`의 네 가이드와 대조해 기존 모든 `<table>`의 셀 내용과 `<pre>` 코드 본문이 동일함을 확인했다. 합성 입력·쿼리·이미지·영상은 수정하지 않았다.
- 로컬 Pages 산출물의 390px 브라우저에서 병합 비교표를 실제 방향키로 이동했다. 표 영역은 337px, 내용은 575px, 방향키 두 번 뒤 `scrollLeft=80`이며 해당 영역에 포커스가 남았다. 문서 전체 폭은 375px로 가로 넘침이 없었다. 본문 건너뛰기도 실제로 `main`에 포커스를 옮겼다.
- 앞자리 0 가이드의 렌더링된 CSV 예제를 기존 공개 변환 도구에 붙여넣고 XLSX를 실제로 내려받았다. ZIP/XML에서 8개 셀(헤더 포함)의 정확한 값, 모두 `inlineStr`, 수식 0개를 확인했다. ID와 수량 모두 문자열이다. 이 검사는 새 native Excel 재계산이나 모든 Excel 환경 검증을 뜻하지 않는다.
- 인쇄 규칙은 CSS 회귀 검사로 확인했다. 이번 작업에서 실제 인쇄 또는 PDF 페이지 배치는 검증하지 않았다.
- 공개 후에는 `node scripts/check-public.mjs`와 실제 운영 페이지의 모바일·키보드 동선을 확인한다. 공개 HTTP 검사에는 21개 사이트맵 경로, 자산 원본 일치, 실제 404, 기존 `.html` 이동이 포함된다.
