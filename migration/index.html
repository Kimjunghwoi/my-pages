글과 도구의 주소

csv.jhsoftlabs.com/guides/…는 jhsoftlabs.com/guides/…로, 도구와 학습은 각각 /workspace와 /learn/excel로 이어집니다. 기존 CSV 홈의 검사기는 CSV 검사기에 있습니다.

학습 진도와 저장 링크가 보이지 않는다면

학습 진도, 저장 링크와 반복 정리 설정은 서버 계정이 아니라 브라우저의 localStorage에 저장됩니다. 호스트가 바뀌면 별도 저장 공간을 사용하므로 이전 값이 자동으로 복사되지 않습니다. 기존 저장값을 삭제하거나 다른 주소로 몰래 전송하지 않습니다.

아래의 이전 주소는 자동 이동을 잠시 피하고 원래 브라우저 저장값을 확인하는 용도입니다. 이전에 사용한 같은 기기·브라우저에서 여세요. 저장 링크를 다시 추가하거나 완료한 학습 항목을 새 주소에서 표시할 수 있습니다. 이전 화면에서 다른 링크를 누르면 새 주소로 이동할 수 있습니다.

이전 저장 링크 확인이전 학습 진도 확인이전 정리 설정 확인

파일은 서버로 옮기지 않습니다

파일 내용과 계산 결과는 기존과 같이 브라우저 안에서 처리합니다. 현재 탭에만 있던 파일·미리보기는 주소 이동이나 새로고침으로 사라질 수 있으니, 필요한 결과는 먼저 내려받으세요. 새 도메인이라고 손상된 원본 값이 복구되거나 모든 대상 서비스에서 사용할 수 있다고 보증하지는 않습니다.
