# 콘텐츠 제작·게시 체크리스트
회몬 · JH Soft Labs | 공개용 v1.0 | 2026-09-13
관련 기록: https://jhsoftlabs.com/stories/salon-publishing.html

내부 운영 문서가 아니라 작업 기록의 시행착오를 바탕으로 새로 만든 빈 양식입니다.
개인·팀 작업에 맞게 복사해 채워 쓰세요. 예시는 가상의 상황이며 고객 자료가 아닙니다.
이 양식은 게시·매출 성과나 자료 사용 권한을 보장하지 않습니다.

## 사용 순서
1. 알릴 내용 한 가지와 원하는 행동 한 가지를 정합니다.
2. 제작 완료와 게시 완료를 각각 확인합니다.
3. 확인된 반응만 기록하고, 모르는 결과는 '미확인'으로 남깁니다.

## 2. 자료와 표현
- [ ] 원본 이미지와 글의 사용 권한을 확인했다.
- [ ] 인물이나 고객 자료가 포함된다면 필요한 동의를 확인했다.
- [ ] AI 생성 예시와 실제 고객 작업·시술 결과를 구분했다.
- [ ] 실제 후기나 성과로 오해할 문구를 제거했다.
- [ ] 연락처 등 민감 정보가 공개 이미지에 남지 않았다.
- [ ] 모바일에서도 핵심 문구와 연결 방법이 읽힌다.

## 3. 공개 전후 확인
- [ ] 최종 파일과 수정 중 파일을 구분했다.
- [ ] 게시글과 이미지의 내용이 일치한다.
- [ ] 연결 페이지가 실제 공개 주소에서 열린다.
- [ ] 문의 링크가 올바른 곳으로 이동한다.
- [ ] 내부 문서나 미공개 파일은 공개되지 않는다.
- [ ] 게시 후 이미지·본문·링크 미리보기를 확인했다.
- [ ] 유료 서비스·호스팅 등의 이용 조건을 별도로 확인했다.
