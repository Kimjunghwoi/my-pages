관련 기록: https://jhsoftlabs.com/stories/salon-publishing.html

내부 운영 문서가 아니라 작업 기록의 시행착오를 바탕으로 새로 만든 빈 양식입니다.
개인·팀 작업에 맞게 복사해 채워 쓰세요. 예시는 가상의 상황이며 고객 자료가 아닙니다.

3. 확인된 반응만 기록하고, 모르는 결과는 '미확인'으로 남깁니다.

- 채널 / 필요한 비율 / 파일 형식:
- 함께 전달할 게시글 / 링크:
- 이번 작업에 포함하지 않는 것:
- 합의한 수정 범위 / 최종 확인자:

## 2. 자료와 표현
- [ ] 원본 이미지와 글의 사용 권한을 확인했다.
- [ ] 인물이나 고객 자료가 포함된다면 필요한 동의를 확인했다.
- [ ] AI 생성 예시와 실제 고객 작업·시술 결과를 구분했다.
- [ ] 실제 후기나 성과로 오해할 문구를 제거했다.
- [ ] 연락처 등 민감 정보가 공개 이미지에 남지 않았다.
- [ ] 모바일에서도 핵심 문구와 연결 방법이 읽힌다.

## 3. 공개 전후 확인

- [ ] 게시글과 이미지의 내용이 일치한다.
- [ ] 연결 페이지가 실제 공개 주소에서 열린다.
- [ ] 문의 링크가 올바른 곳으로 이동한다.
- [ ] 내부 문서나 미공개 파일은 공개되지 않는다.
- [ ] 게시 후 이미지·본문·링크 미리보기를 확인했다.
- [ ] 유료 서비스·호스팅 등의 이용 조건을 별도로 확인했다.

## 1. 독자가 하려는 일
- 글 제목 / 대상 독자:
- 독자가 겪는 증상:
- 원하는 결과:

## 2. 먼저 적는 예상 결과

- [ ] 입력만 보고도 어떤 문제가 있는지 확인할 수 있다.
- [ ] 입력 파일과 절차와 결과가 서로 일치한다.
- [ ] 실행 가능한 코드는 실제로 실행했다.
- [ ] 저장·변환 예제는 출력 파일을 다시 확인했다.
- [ ] 원본을 복사하고 복사본으로 시도하도록 안내했다.
- [ ] 빈 값과 0, 숫자와 식별자를 같은 것으로 설명하지 않았다.
- [ ] 모호한 날짜나 지역 설정의 전제를 명시했다.
- [ ] 합성 데이터만 쓰고 고객 원본을 샘플에 넣지 않았다.
- [ ] 도해가 실제 프로그램 화면인지 설명용 그림인지 구분했다.
- [ ] 맞지 않는 경우와 다음 확인 방법도 적었다.

- [ ] 샘플은 실제로 내려받을 수 있다.
- [ ] 여러 파일이 필요하면 파일별로 구분해 제공한다.
- [ ] 관련 글과 공식 문서 링크가 올바르게 열린다.
- [ ] 제목·설명·대표 주소가 실제 글의 내용과 일치한다.
- [ ] 공개된 페이지에서 마지막으로 절차를 확인했다.
