## 3. 샘플과 설명 점검
- [ ] 입력만 보고도 어떤 문제가 있는지 확인할 수 있다.
- [ ] 입력 파일과 절차와 결과가 서로 일치한다.
- [ ] 실행 가능한 코드는 실제로 실행했다.
- [ ] 저장·변환 예제는 출력 파일을 다시 확인했다.
- [ ] 원본을 복사하고 복사본으로 시도하도록 안내했다.
- [ ] 빈 값과 0, 숫자와 식별자를 같은 것으로 설명하지 않았다.
- [ ] 모호한 날짜나 지역 설정의 전제를 명시했다.
- [ ] 합성 데이터만 쓰고 고객 원본을 샘플에 넣지 않았다.
- [ ] 도해가 실제 프로그램 화면인지 설명용 그림인지 구분했다.
- [ ] 맞지 않는 경우와 다음 확인 방법도 적었다.
