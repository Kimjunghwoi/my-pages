Freeze Rows and Columns Together in Excel: Choose the Correct Cell

A wide export becomes hard to read when the column titles or record IDs disappear. Freeze Panes can retain both, but the active cell determines the boundary. Choosing the wrong cell freezes the wrong part of the sheet.

JHSOFT editorial · Updated September 30, 2026

THE SHORT ANSWER

To keep rows 1–2 and column A visible, first unfreeze any existing boundary, select B3, then choose View > Freeze Panes > Freeze Panes. Excel keeps rows above and columns left of that cell visible. Test vertical and horizontal scrolling separately.

Prepare a sheet with an explicit boundary

Use desktop Excel for Windows and a new worksheet. Put Monthly activity in A1, then put the sample header in A2:E2 and its three records in A3:E5. Keep the title unmerged while testing so it does not distract from which cells are retained.

The first row contains the report title, the second contains field labels, and column A contains IDs. Therefore the desired freeze boundary is below row 2 and to the right of column A. It is a worksheet navigation choice, not a data transformation.

Select the intersection before freezing

If a freeze boundary already exists, use View > Freeze Panes > Unfreeze Panes first. Select the single cell B3, then use View > Freeze Panes > Freeze Panes. Do not choose Freeze Top Row for this two-row example.

The menu options for only the top row or only the first column are convenient for those specific cases. Applying one after another is not a reliable way to build a combined boundary. Use the intersection cell so both dimensions are set in one operation.

Verify vertical scrolling

Scroll downward with the scroll bar while watching the report title and field labels. Rows 1 and 2 should remain at the top; the original row 3 should leave the scrolling area. The fixture contains few records, so the rest of the sheet may be blank. That is enough to test the boundary without inventing extra business data.

If only row 1 stays visible, unfreeze and check the selected row before trying again. If too many rows remain, the active cell was probably farther down. Preserve the data and adjust the view instead of deleting headers to fit an incorrect boundary.

Verify horizontal scrolling independently

Scroll right and confirm that column A remains visible while column B moves. You can temporarily narrow the application window or use the horizontal scrollbar to make this obvious. A narrow worksheet does not need artificially wide data values to prove the rule.

To retain both A and B with the same two header rows, unfreeze, select C3, and freeze again. To retain row 1 and A:B, use C2. These cases are useful controls because changing one coordinate should change only the corresponding boundary.

Distinguish freezing from other view features

Split creates independently scrollable panes and serves a different reading task. If the sheet shows confusing extra panes, inspect View > Split as well as Freeze Panes before assuming the file is broken. Use a normal worksheet view and a single active cell to reproduce the controlled example.

Freeze Panes does not repeat field labels on every printed page and does not prevent editing. Use print-title settings for paper or PDF output, and workbook protection rules for edit restrictions. Those choices solve separate problems.

Save and test the working workbook

Save as XLSX, close the test workbook, and reopen it to inspect the intended view. A CSV stores records and headers, not Excel pane settings. Provide workbook instructions when the receiving person will open a fresh CSV rather than your saved workbook.

The downloadable XLSX already contains the title in A1, field labels in A2:E2 and the three records in A3:E5. Native desktop Excel 16.0 build 5569 opened it with two frozen rows and one frozen column. Moving the native window to row 20 and column 5 preserved that boundary. In a disposable copy, selecting C3 and refreezing retained two rows and two columns, and those settings survived save and reopen. Common questions

Can I freeze an arbitrary row in the middle only?

Freeze Panes retains the rows above the boundary. Reorganize the view or use Split when that does not match your task.

Why is column B moving?

With B3 selected, only columns to its left are fixed. Select C3 to retain A:B.

Will the headers repeat in a PDF?

Configure Print Titles separately; frozen panes are for on-screen navigation.
