Excel Formulas Not Calculating? Check Text, Display Mode, and Calculation Settings

A cell that displays =B2*C2 and a cell that displays yesterday's total have different failure modes. Changing random settings can hide the clue. Start with a copy and one known calculation before replacing formulas across a workbook.

JHSOFT editorial · Updated September 21, 2026

THE SHORT ANSWER

Test =2+3 in a fresh General cell. If formulas appear throughout the sheet, inspect Show Formulas. If one formula is literal text, change that cell to General and re-enter it. If a real formula keeps an old result, check Calculation Options and recalculate. Compare an edited input against its expected new result.

Build a control before editing the workbook

Use desktop Excel for Windows for the menu paths below; other editions can label them differently. Import the synthetic input into A1:C3 on a new worksheet, ensuring B and C contain numbers. Put the label line_total in D1. In F2, enter =2+3 and expect 5. Keep this control away from your source data so troubleshooting cannot overwrite an order.

Record whether the suspect cell shows a formula string, an old number, or an error such as #VALUE!. Errors are calculated results, so do not assume they mean the calculation engine stopped. A custom format can also hide a value; check the formula bar before changing content.

Separate Show Formulas from a text cell

If many formula cells show their expressions, use Formulas > Show Formulas to return to results. That view changes presentation. It does not turn ordinary strings into executable formulas. If only one suspect cell remains literal, inspect its number format and any leading apostrophe or space.

In another empty cell, =ISFORMULA(D2) distinguishes an entered formula from ordinary text on supported Excel versions. A FALSE result is a clue, not permission to execute arbitrary imported strings. Only repair expressions you recognize and intended to calculate.

Repair one intended formula

Select the formula cell, choose General in Home > Number Format, and then press F2 followed by Enter. Changing the format alone may leave existing text unchanged. If the text starts with an apostrophe or space, inspect and remove that prefix only from the intended expression.

For the sample, enter =B2*C2 in D2 and fill to D3. Inspect that the second formula references B3 and C3. Avoid workbook-wide replacement of equals signs: imported notes, identifiers, and strings can intentionally resemble formulas.

Check stale results and calculation mode

When the cell contains a real formula but does not respond to edits, inspect Formulas > Calculation Options. For an ordinary workbook, Automatic is the intended mode. Calculate Now can help distinguish a stale result from an incorrect reference. Calculation settings can affect other open workbooks; check deliberately rather than switching modes repeatedly.

Change B2 to 4 and verify D2 becomes 32. If it stays 24 after recalculation, inspect whether D2 contains a pasted constant, points at another sheet, or uses an absolute reference to a different input. A successful control formula does not verify external connections or every formula in the file.

Reconcile the repaired example

The first result is 3 times 8 plus 2 times 15: 54. The edit adds one unit priced at 8, so the new total is 62. Check both detail lines before trusting the total; a compensating error elsewhere could keep a grand total plausible.

If the imported quantities are text, diagnose that conversion separately. Never reformat a long identifier as a number just because an unrelated amount needs calculation. The linked numbers-as-text guide covers that distinct problem.

Keep a short repair record

Save the repaired copy as XLSX to retain formulas; CSV preserves cell values rather than the workbook's formula structure. Reopen the saved workbook and repeat the small input change before sharing it.

This guide supplies a diagnostic fixture, not proof that every workbook has the same cause. Circular references, broken external links, unsupported functions, and workbook corruption need their own investigation. Capture the exact error and formula when the control passes but the business calculation still fails.

Common questions

Does changing Text to General always fix an existing formula?

No. Re-enter the intended expression after changing the format, then verify an input edit changes its result.

Should I replace every equals sign?

No. Work on one recognized formula first; imported text can intentionally start with formula-like characters.

Why does SUM still return zero?

Inspect whether the summed cells contain numbers. That is different from calculation mode or Show Formulas.
