The main path uses English formula names and Windows desktop menu labels. Each lesson notes its version requirements. Modern lookup and array functions need a supported Excel version; Power Query and What-If menus vary by platform.

Examples use synthetic data. Practice in a separate .xlsx workbook, keep original files, and compare your result with the worked answer. This course covers core Excel and advanced data workflows; VBA, DAX and certification training are outside this edition.
