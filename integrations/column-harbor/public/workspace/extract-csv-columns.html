Complete the task

  1. Read a headered CSV or TSV using the correct input delimiter. Review the detected column names and positions; all columns start selected.
  2. Use Select none, then choose the required columns. Review Columns in output order and use the up and down controls to set the final sequence.
  3. Extract columns and inspect the preview before downloading CSV. Confirm that excluded fields are absent and review the export protection if the recipient needs exact formula-like strings.

Worked example

Load the built-in table, choose Select none, then select order_id and amount. Move amount up so it comes before order_id, then extract. The result has headers amount,order_id and 5 data records; the first pair is 120.50,00101. The duplicate 00101 record remains in its original position. Customer and region are absent from the output.

Method and limits

This selects whole columns and reorders their positions. It does not filter rows, join another table, rename fields or evaluate formulas. Column selection uses positions, so review duplicate or blank header names carefully. At least one distinct column must be selected. A rectangular source header is required, with limits of 5 MiB, 20,000 data records, 200 columns and 250,000 cells including headers. The result is CSV rather than an XLSX workbook. The default export protection may prefix an apostrophe to formula-like values, including negative numbers; the preview is shown before that protection. CSV cannot preserve or enforce spreadsheet cell types.
