1. Clean whitespace in selected columns

Cell line breaks are preserved. Headers are unchanged. Turn off all three operations to skip whitespace cleanup.

2. Optionally remove duplicates by selected keys

Keys compare after step 1. Only the selected key columns determine duplicates; other columns may contain different values.

By default, all rows with an entirely empty key are kept. Partially empty composite keys compare exactly. Spaces count as text unless step 1 removes them.

3. Select and reorder output columns

  3. Column 3: amount

Matching column counts do not establish matching meaning. Review the current headers, cleanup columns, duplicate keys and output order before applying settings to any file.

Complete the task

  1. Read the source and choose the columns for cleanup, duplicate keys and final output order.
  2. Review the current column mapping and run the workflow. Compare the final output with the removed-row report.
  3. Save the settings on this browser. Load a new file, restore the settings and review the mapping again before running.

Worked example

The synthetic order export contains leading-zero IDs, labels with extra spaces and a repeated order. Cleanup runs before duplicate detection; a duplicate report retains the full cleaned row before output columns are removed.

Method and limits

Saved settings contain numeric indices, counts and switches only; no header names, filenames or cell values. Matching column counts do not prove matching column meanings. Settings do not sync between devices. Storage failure leaves the workflow usable. Keeping the first row is an explicit policy, not a claim that the row is newest or correct.
