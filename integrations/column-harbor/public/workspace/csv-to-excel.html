CSV to Excel Without Losing Leading Zeros or Long IDs

A CSV has no cell types. This exporter creates a real Excel workbook with every cell explicitly stored as text, so the original strings remain visible instead of being interpreted as numbers, dates or formulas.

UTF-8 · header plus data rows · up to 5 MiB. Files are read in this browser, without uploading.

Every cell is stored as text, including amounts and dates. This preserves identifiers and literal formula-like values. Convert only the columns you intend to calculate after reviewing them in Excel. Already-lost digits cannot be recovered.

Complete the task

  1. Paste a CSV with its header or read a local UTF-8 text file. Choose Tab when pasting cells from Excel.
  2. Create the workbook and check the preview against the original source.
  3. Download XLSX. Review the file in Excel, then convert only the amount or date columns you intend to calculate.

Worked example

The example preserves product 00123, an 18-digit barcode, 12.50, a negative amount, a two-line note and the literal text =1+1. None of these strings becomes an executable formula.

Method and limits

All cells are text, including quantities and dates. This is a preservation export, not an automatic typed accounting workbook. It cannot recover digits already lost in the source. Input is CSV/TSV, not XLSX; one Data sheet is produced. Unsupported XML controls, excessive cell lengths and oversized output fail rather than being silently removed.
