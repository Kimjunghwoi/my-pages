Shopify Product CSV Checker: Review Import Issues Locally

Check a product CSV before opening the Shopify import screen. This tool reviews supported file rules and shows the exact record, field and value that needs attention. It does not connect to or change your store.

Import purpose

Unchecked: new products. Checked: also review update headers and variant dependencies. This choice does not connect a Shopify store.

The example has three data records. Record 3 is a legitimate additional image row with blank Title, options, price and Status. Record 4 repeats the Small option, uses a currency symbol in Price and supplies the unsupported stock policy stop: expect three local errors.

Complete the task

  1. Select the intended import mode and load a UTF-8 product CSV, retaining a source backup.
  2. Run the supported checks and read errors, warnings and the live-store checklist.
  3. Download the findings, correct the source deliberately and validate the import in Shopify. A clean local report is not import approval.

Worked example

Load the built-in synthetic product example to inspect its declared issues and a legitimate continuation row. A continuation row must not be treated as a separate new product solely because its title is blank.

Method and limits

Rules reviewed October 13, 2026. This is a limited file preflight: store-specific conflicts, inventory locations, metafield references, image availability and import outcomes need Shopify itself. Unknown columns and unsupported formats require review rather than invented errors. No automatic repair or upload is performed.
