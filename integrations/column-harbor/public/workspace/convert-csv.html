Complete the task

  1. Paste a headered delimited table or open a UTF-8 CSV or TSV file. Set Input delimiter to match the source and read the table; use Tab for cells copied from Excel.
  2. Choose Output format. Comma is the initial output; select JSON for an array of objects, or choose semicolon, tab or pipe for delimited text. JSON requires non-empty, unique header names.
  3. Convert the table and inspect the result. JSON values are all strings. For delimited output, review formula-like-value protection and the optional UTF-8 BOM before copying or downloading.

Worked example

Load the built-in order table, choose JSON and convert. The result contains 5 objects: the first order_id is the string "00101", amount is the string "120.50", and the two padded Ana Müller labels remain padded. The repeated 00101 order remains a separate object. Choose Tab instead to export the same four columns and five records as TSV; conversion does not clean whitespace or remove duplicates.

Method and limits

Input must be delimited text with a header and consistent row widths; JSON and XLSX input are unsupported. All JSON values remain strings, including quantities and empty fields; numeric or null typing needs a different explicit conversion rule. Delimited output may change its quoting and line endings while retaining parsed values, except for the selected export protection that can prefix formula-like values with an apostrophe. The tool supports its documented quoting rules, not every TSV dialect. Inputs are limited to 5 MiB, 20,000 data records, 200 columns and 250,000 cells including headers; JSON output is limited to 20 MiB. It cannot restore digits already lost before input.
