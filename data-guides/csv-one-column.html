CSV IMPORT · DELIMITER

CSV가 Excel에서
한 열로 열릴 때

파일이 망가진 것으로 단정하기 전에 원본 텍스트의 구분자와 따옴표를 확인합니다. 원본 파일을 다시 가져오는 방법과 이미 A열에 들어온 온전한 레코드를 나누는 방법은 서로 다른 복구 경로입니다.

회몬11년차 개발자 · Column Harbor 운영
2026. 09. 19.
먼저 기억할 것
  1. 복사본의 원본 텍스트에서 실제 구분자를 찾습니다.
  2. 식별자는 Text로, 숫자는 목적에 맞는 자료형으로 가져옵니다.
  3. 레코드 수·열 수·문장 부호·앞자리 0을 함께 확인합니다.

예시는 합성 데이터입니다. 메뉴 이름은 Excel 버전에 따라 다를 수 있습니다.

이 글에서왜 한 열로 열리는가원본에서 구분자 확인원본 파일 다시 가져오기Text to Columns 사용 조건결과 검증

01 / CAUSE

쉼표 파일이라고
추측하지 않습니다

CSV라는 이름은 흔히 쉼표로 구분된 파일을 뜻하지만, 실제 업무 시스템은 지역 설정이나 내보내기 규칙 때문에 세미콜론이나 탭을 사용할 수 있습니다. Excel이 예상한 구분자와 파일의 실제 구분자가 다르면 한 줄 전체가 셀 하나에 들어갑니다. 이때 확장자를 바꾸거나 모든 문장 부호를 일괄 치환하면 데이터 내용까지 바뀔 수 있습니다.

특히 설명 필드 안의 쉼표는 구분자가 아닐 수 있습니다. 따옴표로 감싼 "Mug, blue"의 쉼표는 제품 설명의 일부입니다. 어떤 기호가 자주 보인다는 이유만으로 구분자로 선택하면 열이 과도하게 늘어납니다.

02 / INSPECT

작은 합성 예제로
경계를 먼저 봅니다

복사본을 메모장 같은 일반 텍스트 편집기로 열고 헤더와 두세 줄을 확인합니다. 다음 예제는 세미콜론 세 개의 열을 만듭니다.

sku;description;price

00123;"Mug, blue";12.50
00456;"Plate; small";8.00

헤더에서 sku, description, price 사이를 나누는 기호는 세미콜론입니다. 첫 설명의 쉼표와 둘째 설명의 세미콜론은 각각 값 안의 문장 부호입니다. 둘째 설명은 따옴표 안에 있으므로 세미콜론 구분자를 써도 하나의 필드로 남아야 합니다.

03 / IMPORT

가장 안전한 경로는
원본을 다시 가져오는 것입니다

  1. 새 통합문서에서 Data → From Text/CSV를 엽니다.실패한 시도가 정리한 표를 덮어쓰지 않도록 새 시트나 새 파일을 사용합니다.
  2. 미리보기에서 Delimiter를 Semicolon으로 지정합니다.세 열이 보이고 Plate; small이 하나의 설명에 남는지 확인합니다.
  3. sku 열은 Text로 지정합니다.00123이 123으로 바뀌기 전에 식별자임을 명시합니다. 자동 Changed Type 단계가 먼저 생겼다면 제거한 뒤 자료형을 정합니다.
  4. price만 숫자로 변환하고 Close & Load를 선택합니다.숫자 표시가 12.5로 보여도 값 12.50과 수치상 같을 수 있으므로 서식과 값 변환을 구분합니다.

04 / ALTERNATIVE

Text to Columns는
레코드가 온전할 때만

각 A열 셀에 한 레코드가 완전히 남아 있다면 Data → Text to Columns → Delimited 경로를 사용할 수 있습니다. 원본 열을 복사하고 빈 출력 위치를 정한 뒤, 세미콜론과 double quote 텍스트 한정자를 선택합니다. 마지막 단계에서 sku 열을 Text로 지정합니다.

따옴표 안에 줄바꿈이 있어 이미 여러 worksheet 행으로 갈라졌거나, 식별자의 앞자리 0이 사라졌거나, 날짜가 이미 변환됐다면 이 경로로 원래 값을 복원할 수 없습니다. 그때는 untouched 원본 파일로 돌아가 From Text/CSV를 사용해야 합니다.

05 / VERIFY

열이 생긴 것만으로
성공이라 하지 않습니다

예상 결과는 데이터 레코드 2개, 열 3개, sku 00123과 00456, 설명 Mug, blue와 Plate; small, 가격 합계 20.50입니다. 합계만 맞아도 설명이나 ID가 손상될 수 있으므로 각 항목을 대조합니다.

실제 파일이 크다면 첫 줄과 마지막 줄, 따옴표·문장 부호·빈 필드가 있는 레코드를 표본으로 확인합니다. 원본을 함께 보관하면 다음 새로고침에서 가져오기 설정이 달라졌는지 비교할 수 있습니다.
